# DuelDeck

游戏王 Master Duel 助手：一键 Solo 通关、自己组卡组和写出招规则，还能接入你自己的 AI，实时出主意、复盘对局。

本仓库只放编译好的发布包和更新文件，不含源代码。

## 下载与安装

1. 打开本页右侧的 **Releases**，下载最新的 `DuelDeck-版本号.zip`。
2. 解压到一个新文件夹。
3. 双击文件夹里的「启动 DuelDeck.bat」。

## 运行环境

- Windows 10 / 11（64 位）
- Steam 版《游戏王 Master Duel》

## 更新

- 已经装过的不用重新下载：程序启动时会自动检查并下载更新，下次启动时换上。
- 提示「版本过期」时，等程序在后台下完新版，按提示重启即可。
- 版本号早于 2026.9.30.2112 的老版本不会自动更新，请重新下载最新的完整包，解压到新文件夹使用。

## 主要功能

- **Solo 通关**：一键把单人模式的关卡打完。
- **我的卡组**：自己组卡组，复制卡组码。
- **卡组规则**：用表单给自己的卡组写出招规则，比如先发哪张、什么时候不发动。
- **AI 参谋**：你自己打，AI 在旁边实时给建议。
- **AI 助手**：接入你自己的 AI，复盘对局、帮你写规则。支持 Claude、DeepSeek、OpenAI、通义千问、智谱、Kimi、硅基流动、火山引擎豆包等。
- **MCP 扩展**：给 AI 接上网页搜索等额外工具。
- **决斗小精灵**：右下角的对话助手，说一句话就能操作软件，也能直接把问题反馈给作者。
